# Highlights (for Applied Sciences submission)

*MDPI recommends 3–5 bullet highlights; each should be a single sentence of ≤ 85 characters.*

---

- We define Tool-Layer Presentation Errors (TLPEs), a failure class distinct from hallucination.
- Six TLPE classes are documented from real user incidents in a blockchain insurance chatbot.
- Four targeted mitigations (server-side strings, enumeration prompts, SSE flags, history tracking) are proposed.
- A 49-query before/after harness with on-chain ground truth evaluates mitigation effectiveness.
- The taxonomy generalizes to any LLM agent reporting arrays, timestamps, or status codes.
