# [학술대회 축약본] 약관 기반 보험심사 캐스케이드: 규칙과 LLM의 경계, 그리고 재현성 함정

## 1. 문제와 접근

청구·계약 심사는 소액·정상건을 규칙으로 자동 처리하고 나머지를 사람에게 상신하는 2단계다. 여기에 LLM을 넣자는 제안이 많으나, **어디에 두어야 하고 어떤 조건에서 안전한지**는 함께 측정된 바가 드물다.

핵심 관찰: **정액(비실손) 치아보험**에서 적격성 판단은 취향이 아니라 **상품 약관으로 결정**된다. 두 귀결:
1. **정답은 구성상 객관적** → 사람 gold 라벨 불필요(보험사 차이 = 서로 다른 약관 = 3개 규칙 프로파일로 모델링, 노이즈 아님).
2. **구조화 결정의 올바른 도구는 LLM이 아니라 결정론적 규칙엔진**(객관·감사가능·무비용).

따라서 LLM은 **규칙이 인코딩 못 하는 잔여**에서만 자리를 얻는다 — (가) 자유텍스트→사실(코드-설명 불일치·업코딩), (나) 자연어 약관 적용. 이를 **약관 기반 캐스케이드**로 제안·검증한다: 규칙 1차 → 약관 그라운딩 LLM 2차(승인/조사/부지급) → 사람 확정. (정액 상품이라 **금액적정성은 범위 제외**.)

## 2. 실험 설계

- **실험1(자유텍스트 잔여, 294건, A3 제외)**: 재현 가능한 역량 모델 `gpt-5.5`와 로컬 2종(Qwen-14B, DeepSeek-R1)이 동일 중립 프롬프트로 블라인드 건별 판정, 약관유도 정답과 대조.
- **실험2(약관 적용, 180건=60시나리오×3프로파일)**: gpt-4o/mini·Qwen이 **T0 약관없음 / T1 깔끔한 조항 / T2 실제 약관 원문** 3조건에서 3분류(지급/감액/부지급).
- 규칙 베이스라인(파이썬)으로 LLM 없이 규칙이 처리하는 범위를 확정.

## 3. 결과

**(1) 규칙의 경계** — 규칙은 구조적 이상(중복·분할·면책)은 ~100% 잡지만 **코드-설명 불일치(A2)는 0%**. 20% 자동지급에서 이상의 34% 누수. → LLM의 잔여가 명확.

**(2) 잔여에서의 LLM (표)**

| 지표(A3 제외) | gpt-5.5 | Qwen | DeepSeek |
|---|---:|---:|---:|
| 전체 | **72.4%** | 54.4% | 53.7% |
| 코드-설명 불일치 A2 | **95%** | 40% | 55% |
| 업코딩/텍스트전용 | **100%** | 17% | 100%\* |
| 정상건 특이도 | 51.8% | 67.9% | 31.4% |
| 위험누수 / 과잉조사 | **11 / 70** | 88 / 46 | 42 / 94 |
| 인젝션 수행(11중) | **0** | 4 | 7 |

\* 과잉조사의 산물. — 역량 모델은 **고재현율·보수적**: 규칙이 못 잡는 이상을 95~100% 잡고 인젝션을 전부 막되, 정상건을 과잉조사(안전 방향)한다. 로컬 모델은 우연·위험(누수/인젝션).

**(3) 약관 적용 (표)**

| 모델 | T0 사실만 | T1 깔끔조항 | T2 실제약관 |
|---|---:|---:|---:|
| gpt-4o | 37% | **88%** | 69% |
| gpt-4o-mini | 33% | 67% | 35% |

→ **같은 객관 정답인데 제시형식(없음/요약/원문)만으로 37→88→69% 출렁**이고 작은 모델은 붕괴. 약관 그라운딩은 필수·형식/모델 민감.

**(4) 재현성 함정(방법론적 발견)** — 프로젝트 맥락을 본(비블라인드) 어시스턴트 세션은 역량 모델을 **91%**로 보고했으나, 블라인드 건별 API에서는 **72%**. 격차 ~19%p가 거의 전부 정상건 특이도(89.8%→51.8%). → **세션 기반 LLM 평가는 정확도를 과대추정**하므로 블라인드·건별 측정이 필수.

## 4. 결론·향후

- 구조화 결정은 규칙엔진, LLM은 **약관 그라운딩된 텍스트 잔여의 고재현율·안전방향 1차 필터**(사람 확정 하), 모델 선택은 안전 파라미터.
- 정답=약관이므로 **사람 gold 없이 평가 가능**.
- **향후(발표 시 "진행 중"으로 구분)**: 사람 전문가 검증 서브셋, 다중 시드, 신뢰도 보정, 전통 ML 베이스라인, 리더 스터디(IRB). 모든 수치는 합성 기준이며 외부 타당성은 한계로 명시.
