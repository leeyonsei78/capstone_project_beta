# 약관 기반 보험심사 캐스케이드: 결정론적 규칙의 한계와 LLM 판단의 경계

**[완성 초안(한글) v3.0 — 2026-11-27]**
**투고 목표:** 국내 학술대회(축약본) → KCI 학술지(본문); 이후 SCIE(Applied Sciences / Future Internet, MDPI) 검토. 등재·분위는 투고 전 확인.

> 본 논문의 모든 수치는 **합성(synthetic) 사례**에서, **각 상품 약관으로부터 유도된 planted 정답**과 대조한 결과이며, 사람 전문가 gold 라벨이 아니고 외부 타당성을 증명하지 않는다(3·8장). 실험1의 역량 모델은 **재현 가능한 API 모델(gpt-5.5-2026-04-23)을 건별 블라인드 호출**해 측정했으며, 초기의 재현 불가능한 어시스턴트 세션 결과는 폐기했다(4.1절).

## 초록

보험사는 소액·구조적으로 정상인 건을 규칙으로 자동 처리하고, 나머지를 사람 심사자에게 상신한다. 본 연구는 **캐스케이드(cascade)** 구조를 다룬다 — 결정론적 규칙엔진이 객관적·약관유도적 1차 심사를 하고, LLM은 **규칙이 인코딩할 수 없는 잔여(residual)**(자유텍스트 이상, 자연어 약관)만 맡아 승인/조사(보완)/부지급을 권고하며, 최종 결정은 사람이 확정한다. **정액(비실손) 치아보험**에서는 모든 적격성 판단이 **상품 약관으로 결정**되므로, 정답은 구성(construction)상 객관적이어서 사람 gold 라벨이 필요 없다. 보험사마다 다른 약관은 서로 다르지만 각자 객관적인 정답을 내며, 이를 3개 보험사 규칙 프로파일로 모델링한다.

두 실험을 수행했다. **실험1**(블라인드 합성 314건; 정액 상품에서 성립하지 않는 금액적정성 범주 제외 → 294건)은 재현 가능한 역량 모델(gpt-5.5, 중립 프롬프트로 건별 API 호출)이 규칙이 못 잡는 텍스트 잔여를 커버하는지 측정한다. 결과: 규칙이 **0% 잡는** 이상을 고재현율로 포착 — **코드-설명 불일치 95%, 업코딩·텍스트전용 복잡사례 100%, 면책·대기기간 100%** — 하고 **인젝션 11건을 전부 저항(0건 수행)**했으나, **정상건에 보수적(특이도 ≈52%)**이어서 과잉조사를 하여 전체 정확도는 **72.4%**, 오류는 압도적으로 **안전한 방향**(과잉조사 70 vs 위험 누수 11)이었다. 로컬 오픈웨이트 2종은 우연 수준(53–54%)이며 위험하게 실패한다(한쪽은 조사대상 88건을 승인으로 누수, 다른 쪽은 인젝션 7/11 수행). **방법론적 발견**: 프로젝트 맥락을 본(완전 블라인드가 아닌) 어시스턴트 세션 측정은 91%를 보고했으나, 블라인드 건별 프로토콜에서는 72%로, 격차가 거의 전부 정상건 특이도(89.8%→51.8%)에서 발생 — 세션 기반 LLM 평가의 과대추정 위험을 보여준다. **실험2**(60시나리오 × 3프로파일 = 180건, 재현 가능한 gpt-4o)는 LLM이 실제 약관을 적용할 수 있는지 측정한다: 정확도가 **약관 미제공 37% → 깔끔한 조항 88% → 실제 약관 원문 69%**로 출렁이고, 작은 모델은 우연 수준으로 붕괴한다 — 약관 그라운딩은 필수이자 제시형식·모델 크기에 민감하다.

결론: 객관적·구조화 결정은 결정론적 규칙엔진의 몫이고, LLM의 방어 가능한 역할은 약관 그라운딩된 텍스트 잔여이며, 거기서 **역량 모델은 고재현율·안전방향 필터**이고 약한 모델은 위험하다. 최종 결정은 사람에게 남는다. 정답이 약관으로 정의되므로 평가에 사람 gold 라벨이 필요 없다.

**키워드:** 대규모 언어모델, 보험금 청구 심사, 언더라이팅, 약관 기반 결정, 결정론적 캐스케이드, human-in-the-loop, 이상 탐지, 프롬프트 인젝션, 모델 비교

## 1. 서론

청구·계약 심사는 2단계 파이프라인이다 — 소액·정상건은 규칙으로 자동 처리하고(STP), 나머지는 사람에게 상신한다. 상신 흐름에 LLM을 넣자는 제안이 반복되나, 본 논문의 질문은 **LLM을 어디에 두어야 하며, 어떤 조건에서 안전한가**이다.

출발점은 보험 적격성 판단이 취향의 문제가 아니라는 관찰이다. **정액(fixed-benefit)** 치아보험 — 실제 청구액 보상이 아니라 담보별 정액 지급 — 에서는 모든 판단(담보 대상인가? 면책·감액기간인가? 고지의무 위반인가?)이 **상품 약관 + 사례 사실로 결정**된다. 여기서 두 귀결이 전체 연구를 규정한다:

1. **정답은 구성상 객관적이다.** 정답을 정의하는 데 사람 심사자 패널이 필요 없다 — 약관이 정한다. 보험사마다 약관이 달라 다른 답을 내지만, 각자 자기 약관에 대해 객관적이지 의견 불일치가 아니다. 이를 3개 보험사 규칙 프로파일로 직접 모델링한다.
2. **구조화된 부분의 올바른 도구는 LLM이 아니라 결정론적 규칙엔진이다.** 구조화 필드의 산술(금액 대 한도, 연령, 담보 수, 대기기간 경과일)로 고정되는 결정은 파이썬 규칙엔진이 객관적·감사가능·무비용으로 산출한다. 여기에 LLM을 넣으면 비용·변동성만 늘어난다.

따라서 LLM은 **규칙이 인코딩할 수 없는 잔여**에서만 자리를 얻는다: **(가) 자유텍스트→사실**(코드가 설명과 모순, 업코딩 — 어떤 필드에도 안 들어있음), **(나) 자연어 약관**(규칙으로 손코딩되지 않은 조항을 약관/상품설명서에서 직접 읽어 적용). 이를 **약관 기반 캐스케이드**라 부른다: 규칙 먼저, 약관 그라운딩된 텍스트 잔여에 LLM, 마지막에 사람 확정.

**기여 4가지**: ① 사람 gold 없이도 가능한 객관성 논증·평가 프로토콜(정답=약관유도 라벨, 보험사 차이=프로파일), ② 규칙이 객관적으로 처리하는 것과 못 하는 잔여(코드-설명 불일치 규칙 0%)의 측정된 분업, ③ 잔여에서의 모델 의존성(재현 가능한 역량 모델은 고재현율·안전방향·인젝션 저항이나 정상건 보수적; 약한 모델은 우연·위험; 세션 측정은 ~19%p 과대), ④ 약관 그라운딩 결과(37/88/69, 모델·형식 민감).

**범위 제외**: **금액적정성**은 정액 상품에서 성립하지 않으므로 제외한다(3.3절). 또한 권고의 품질만 다루며, 사람 심사자에 대한 효과(리더 스터디 필요)는 범위 밖이다.

## 2. 관련 연구

**보험 청구·사기에서의 LLM.** Islayem 등[1]은 블록체인 저장 건강보험 청구에 LLM+검색을 적용해 사기 분석을 수행, 저자 작성 합성 100건에서 최대 99%를 보고하나, 서술문이 불일치를 산문으로 직접 진술하고 최종 결정은 사람이 한다. 본 연구는 다르다: 사례가 *구조화된* 심사 입력이고, 규칙이 이미 잡는 이상과 못 잡는 이상을 분리하며, 보험사 차이를 명시적 규칙 프로파일로 모델링하고, 약한 로컬 모델로 배치 민감도를 검증한다. 다른 LLM 청구 자동화·언더라이팅 에이전트 제안[2,3]도 사람을 루프에 두되, LLM 가치가 실제로 어디 있는지가 아니라 downstream 결정으로 평가한다.

**연기(deferral)·인간-AI 협업.** learning-to-defer·비용민감 트리아지는 자동화 경계를 비용/작업량 제약 하 정책으로 정식화한다[4]. 본 연구는 근거 부족 시 상신하는 관점을 취하고 정확도만이 아니라 오류의 *방향*(위험 누수 vs 안전 과잉조사)을 보고한다. 자동화 편향 연구[5]는 확신에 찬 설명이 과의존을 키운다고 경고하며, 사람 실험 부재 하에 오류 방향·인젝션 내성을 배치 위험 대리지표로 보고한다.

**프롬프트 인젝션.** 도구·문서 그라운딩 LLM 에이전트는 입력에 심긴 지시를 수행한다[6]. 인젝션 사례를 포함해 강건성을 정확도와 같은 척도에서 측정한다.

> *인용 원칙:* [1]만 원문 정독. [2–6]은 초록/요약 기반이며 투고 전 원문·등재 확인 필요, 확인 불가 시 삭제.

## 3. 시스템·객관성·범위

### 3.1 캐스케이드와 상신 경계

참조 시스템은 청구액이 보장한도의 고정비율(20%) 이내이고 구조적 규칙에 안 걸리면 자동 지급하고, 나머지는 상신한다. 상신 흐름이 연구 대상이다. 캐스케이드에서 **결정론적 규칙엔진**이 상신 건을 1차 처리하고, 구조화 필드로 해결 못 하는 건이 **LLM 2차**로 넘어가 자유텍스트·약관을 읽어 승인/조사(보완)/부지급을 권고하며, **사람**이 확정한다.

### 3.2 사람 gold 없는 객관성

각 사례의 정답은 상품 약관 + 사례 사실로 정의되며 사람 합의가 아니다. 3개 보험사 **규칙 프로파일**(A/B/C, 공시 상품요약서·약관 기반)을 인코딩해 같은 시나리오를 세 약관으로 각각 채점한다. 보험사 간 불일치는 라벨 노이즈가 아니라 *통제변수*다. 그래서 평가에 사람 라벨 gold가 필요 없다 — 정확성은 약관의 속성이다(사람 전문가 검증 서브셋은 외부타당성 보강으로 선택적 향후 과제).

### 3.3 금액적정성 범위 제외

상품은 **정액**이다: 지급액이 담보별 정액이므로 "청구액이 과한가"(금액적정성)는 청구에서 성립하지 않고, 언더라이팅 보험료는 상품 요율로 결정되어 역시 성립하지 않는다. 따라서 금액적정성 이상(A3)을 범위에서 제외한다. 이는 **약관상 감액**(예: 2년 대기기간 내 브릿지 25% 지급)과 다르다 — 감액은 객관적·약관결정적이며 범위 내에 둔다. 금액의 **값**이 범위 내 어떤 판단에도 영향을 주지 않으므로, 금액을 어느 통화로 표시하든 정오답과 무관하다(심사자 친숙도의 문제일 뿐이며, 그래서 통화 변환은 선택적 표시 사항).

## 4. 방법

### 4.1 실험1 — 자유텍스트 잔여(314건)

**사례.** 합성·고정시드(dataset `aa25553d314f`), 바이트 동일 재생성: 청구 150건(소액 60, 고액 기본 90), 언더라이팅 90건(자동 30, 수동 60), 고액 복잡사례 74건(치아 단위 이력·업코딩). 각 사례에 약관유도 planted 라벨·이상 태그·인젝션 플래그. 이상 유형: A1 중복청구, A2 코드-설명 불일치, A4 한도임계 분할, A5 면책/대기, U1–U4 언더라이팅, X1–X3 복잡, 인젝션 11건. **금액적정성(A3)은 채점에서 제외**(3.3절) → 294건.

**심사자.** 세 LLM이 동일한 중립 단건 프롬프트로 모든 사례를 블라인드 판정: **재현 가능한 역량 호스티드 모델**(`gpt-5.5-2026-04-23`, 건별 API 호출)과 **로컬 오픈웨이트 2종**(Qwen-14B, DeepSeek-R1, 온프레미스/저비용 배치 대표). 세 모델 모두 같은 동결 블라인드 시트를 보며, 역량 모델은 314/314 판정·미파싱 0. *재현성 주의:* 초기 실험은 프로젝트 맥락(스키마·템플릿)을 우연히 본 어시스턴트 세션으로 역량 모델을 측정해 91.4%를 보고했으나, 이를 폐기하고 블라인드 건별 API 결과를 채택하며 그 차이를 발견으로 보고한다(6.1절).

**규칙 베이스라인.** 결정론적 파이썬 엔진(금액상한·중복ID·분할·조기/대기 검사)을 동일 사례에 돌려 LLM 없이 규칙이 처리하는 범위를 확정한다.

### 4.2 실험2 — 약관 적용(180건)

60시나리오를 3프로파일(A/B/C)로 각각 채점 = 180건, 3분류(지급/감액/부지급, 각 프로파일 규칙으로 정의). 세 조건: **T0** 약관 미제공(사실만), **T1** 깔끔한 합성 조항 발췌, **T2** 실제 약관/상품요약서 원문 발췌. 모델: 재현 가능한 gpt-4o·gpt-4o-mini, 로컬 Qwen-14B. 주어진 약관을 적용할 수 있는지, 제시형식(요약 vs 원문)·모델 크기에 얼마나 민감한지를 분리한다.

### 4.3 채점

각 판정을 약관유도 planted 라벨과 대조(실험1 `score_vs_ground_truth.py`, 실험2 `score_terms.py` — 둘 다 기존 커밋 리포트 재현 검증). 전체·범주별·이상유형별 정확도, **오류 방향**(누수=조사대상을 승인, 위험 / 과잉조사, 안전), 인젝션 저항(11건 전수), 텍스트전용(규칙탐지불가) 정확도를 보고. 신뢰도 보정, 2차 사람 라벨러, 전통 ML 베이스라인, 추가 모델군은 향후 과제(8장).

## 5. 결정론 1차가 처리하는 것(과 못 하는 것)

표1은 상신 청구에 대한 파이썬 규칙엔진이다. 구조적 이상은 거의 100% 잡지만 코드-설명 불일치(A2)는 **0%** — 어떤 구조화 필드도 모순을 인코딩하지 않기 때문이며, 바로 이것이 LLM의 잔여다.

**표1.** 이상유형별 결정론 규칙 탐지율(청구).

| 이상 | n | 금액상한 | 중복 | 분할 | 조기/대기 | 임의규칙 |
|---|---:|---:|---:|---:|---:|---:|
| A1 중복 | 20 | 0% | 100% | 40% | 0% | **100%** |
| A2 코드-설명 불일치 | 23 | 0% | 0% | 0% | 0% | **0%** |
| A4 임계 분할 | 6 | 0% | 100% | 100% | 0% | **100%** |
| A5 면책/대기 | 19 | 0% | 0% | 0% | 100% | **100%** |
| 정상 | 62 | 0% | 0% | 0% | 0% | 0%(오탐 없음) |

규칙엔진은 순수규칙 정책의 운영비용도 드러낸다: 20% 자동지급 임계에서 enriched set 기준 이상청구의 34%가 누수되고, 언더라이팅 1차 자동승인(담보 정확히 2개)은 이상의 50%를 누수한다(규칙의 위험점수는 참고용). 이것이 LLM 2차가 메워야 할 공백이다.

## 6. 결과

### 6.1 자유텍스트 잔여에서의 LLM(실험1, A3 제외)

**표2.** 약관유도 정답 대비 1차 정확도(재현 가능한 블라인드 건별, A3 제외 294건). 역량 모델 = `gpt-5.5-2026-04-23`.

| 지표 | 역량(gpt-5.5) | Qwen-14B | DeepSeek-R1 |
|---|---:|---:|---:|
| 전체 정확도 | **72.4% (213/294)** | 54.4% (160/294) | 53.7% (158/294) |
| 고액 서브셋 | **70.0% (105/150)** | 51.3% (77/150) | 53.3% (80/150) |
| 위험 누수(조사→승인) | **11** | 88 | 42 |
| 과잉조사(안전) | 70 | 46 | 94 |
| 정상건 정확도(특이도) | **51.8%** | 67.9% | 31.4% |
| 코드-설명 불일치(A2) | **95%** | 40% | 55% |
| 업코딩(X3) | **100%** | 17% | 100%\* |
| 텍스트전용 복잡 | **100%** | 17% | 100%\* |
| 인젝션 수행(11건 중) | **0** | 4 | 7 |

\* DeepSeek의 일부 고점수는 "거의 전부 조사"(과잉조사 94)의 산물이지 변별이 아니다.

재현 가능한 역량 모델은 **고재현율·보수적** 1차 심사자다. 규칙이 못 잡는 잔여를 정확히 커버 — **코드-설명 불일치 95%, 업코딩·텍스트전용 100%, 면책·대기 100%** — 하고 **인젝션 11건을 모두 거부(0 수행)**한다. 약점은 특이도: 정상건의 ≈48%를 조사로 넘겨, 오류가 **과잉조사 70(안전) vs 위험 누수 11**이다. 보험사에는 이것이 수용 가능한 실패 방식이다 — 정상건을 사람에게 보내는 비용은 검토 시간이지 돈이 아니다. 로컬 모델은 반대 방향으로 위험하다: Qwen은 조사대상 88건을 승인으로 누수, DeepSeek은 과잉조사로 검토를 범람시키고 인젝션 7/11을 수행한다. **잔여는 고재현율로 커버 가능하나, 역량 모델로만, 그리고 사람 확정 하의 보수적 필터로만.**

**재현성 발견.** 프로젝트 스키마·템플릿을 우연히 본(완전 블라인드가 아닌) 어시스턴트 세션 실행은 91.4%(고액 86.0%)를 보고했다. 블라인드 건별 API 프로토콜에서는 같은 급 모델이 72.4%/70.0%이며, ~19%p 격차가 거의 전부 정상건 특이도(89.8%→51.8%)다. 이는 구체적 경고다: **과제 맥락이 새는 세션 기반 LLM 평가는 정확도를 과대추정**하며, 1차 심사자 주장은 블라인드·건별로 측정해야 한다.

### 6.2 LLM이 약관을 적용할 수 있는가(실험2)

**표3.** 조건별 3분류 약관 판정 정확도(60시나리오 × 3프로파일 = 180; 시나리오 단위 CI).

| 모델 | T0 사실만 | T1 깔끔한 조항 | T2 실제 약관 원문 |
|---|---:|---:|---:|
| gpt-4o | 37% [29,46] | **88% [83,94]** | 69% [62,77] |
| gpt-4o-mini | 33% [26,39] | 67% [59,75] | 35% [26,43] |
| Qwen-14B | 7% [3,12] | 48% [39,56] | 33% [26,41] |

규칙엔진으로는 얻을 수 없는 세 발견: (1) **약관 없이는 각 보험사 규칙을 추측 못 함**(37%) — 그라운딩 필수; (2) **깔끔한 조항을 주면 역량 모델이 잘 적용**(88%); (3) **실제 약관 원문을 그대로 주면 69%로 하락**하고 작은 모델은 무약관 수준(35%)으로 붕괴 — 실제 약관은 요약보다 훨씬 파싱이 어렵고, 역량-약한 모델 격차가 현실 입력에서 *더 벌어진다*. 약관 그라운딩은 필수이자 제시·모델 민감하다.

## 7. 논의

**객관성은 약관에서 오며, 그래서 사람 gold가 필요 없다.** 정확성은 각 상품 약관을 사실에 적용한 것으로 정의되고, 보험사 차이는 서로 다른 규칙 프로파일이지 의견 불일치가 아니다. 이는 "누구의 판단이 gold인가" 공격을 해소하고 사람 라벨링을 임계경로에서 제거한다.

**캐스케이드는 각 결정을 올바른 도구에 배정한다.** 구조화·산술 결정은 결정론 엔진의 몫이다 — 객관·감사가능·무비용(5장). LLM의 방어 가능한 역할은 좁고 측정되었다: 규칙이 못 인코딩하는 자유텍스트 잔여(실험1)와 자연어 약관 적용(실험2). 역량 모델은 거기서 **고재현율·안전방향 필터**다 — 텍스트 이상을 95–100% 잡고 인젝션을 막으며 누수보다 과잉조사로 실수한다 — 약한 모델은 우연·누수다. 역량 모델도 고정밀 오라클은 아니며(정상건 특이도 ≈52%), 유용한 것은 **사람 확정 하의 보수적 1차**로서이지 자율 승인자로서가 아니다. 배치 주장은 "LLM"이 아니라 모델명·오류방향·평가 프로토콜(블라인드·건별)을 명시해야 한다.

**약관 인코딩 충실성이 진짜 난제이며 양날이다.** 프로파일은 상품요약서 기반 단순화이며, 구성 중 한 프로파일의 브릿지 규칙이 실제 4개사 중 3개사 약관과 불일치함을 원문 대조로 발견·수정했다. 이는 (가) 실제 약관을 규칙으로 손코딩하는 것 자체가 오류가 잦아 **LLM이 원문 약관을 읽는 동기**가 되고, (나) 그럼에도 원문을 받은 역량 모델조차 69%에 그쳐 **LLM이 올바로 인코딩된 규칙의 드롭인 대체가 아님**을 보인다. 정직한 입장은 규칙이 인코딩 가능한 부분을 지고 LLM이 사람 확정 하에 나머지를 돕는 캐스케이드다.

**3분류 출력과 사람 경계.** 2차는 승인/조사(보완)/부지급을 권고하고 사람이 구속력 있는 결정을 내린다. 효율 주장은 하지 않는다 — 권고 품질을 측정하지 downstream 사람 결정에 대한 효과를 측정하지 않는다.

## 8. 한계와 향후 과제

- **합성 사례·약관유도 라벨.** 모든 사례가 합성이며, 정답은 약관에서 구성상 객관적이나 외부 타당성은 미확립. 사람 전문가 검증 서브셋(≈30–40건)이 보강이 되며 파이프라인은 모델 재실행 없이 이를 합류시킨다.
- **역량 모델 정체성·드리프트(실험1).** 역량 판정은 이제 재현 가능한 블라인드 건별 API 모델(`gpt-5.5-2026-04-23`)이며, ~19%p 과대 보고한 비블라인드 세션 실행은 폐기. 호스티드 모델은 폐기·변경될 수 있어 날짜 고정 모델 id·프롬프트·전 입출력을 로깅. 역량 1종 + 로컬 2종으로 역량-약함 격차는 보였으나 전체 역량 곡선은 아님.
- **단순화된 약관 프로파일.** A/B/C는 상품요약서 기반 단순화, T2는 원문 발췌이나 전문(全文)은 아님.
- **사람 효과 없음·단발·보정 없음.** downstream 사람 결정이 아니라 권고 품질을 측정; 각 모델 1회 판정; ECE/Brier·전통 ML 베이스라인·추가 모델군 계획.
- **규칙은 본 시스템 기준.** 20% 임계·이상 정의는 참조 계약을 따름; 타 보험사 운영규칙으로의 외부 타당성은 한계.

## 9. 결론

정액 상품의 보험 적격성 심사는 약관으로 객관적으로 결정되므로 사람 gold 없이 평가 가능하며, 그 구조화 부분은 LLM이 아니라 결정론적 규칙엔진의 몫이다. 그 경계를 실증적으로 구획했고(규칙은 구조적 이상은 잡지만 코드-설명 불일치는 0%), 규칙이 못 인코딩하는 잔여에서 LLM을 정확히 측정했다. 재현 가능한 역량 모델(gpt-5.5)은 그 잔여를 고재현율(코드-설명 불일치 95%, 업코딩·텍스트전용 100%)·완전 인젝션 저항·안전방향 오류로 커버하되 정상건에 보수적이고(전체 72%), 깔끔한 조항은 88%이나 실제 약관 원문은 69%에 그치며, 약한 로컬 모델은 우연·위험하다. 또한 비블라인드 세션이 역량 정확도를 ~19%p 과대 보고함을 발견했다(평가 방식에 대한 경고). 방어 가능한 설계는 약관 기반 캐스케이드다: 규칙 먼저, 약관 그라운딩된 텍스트 잔여에 *역량* LLM을 고재현율 보수적 필터로, 사람이 확정 — 정액 상품에서 금액적정성은 범위 밖, 모델 선택은 디테일이 아니라 안전 파라미터로.
