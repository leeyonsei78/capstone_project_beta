AI 에이전트는 보험 심사를 어디까지 맡을 수 있는가: 구현된 계약 심사 자율화와 보험금 청구 자율 판정의 가능성

계약 심사(언더라이팅)에서는 구현된 다중 에이전트 자율 심사를 제시·검증하고, 보험금 청구에서는 선행연구가 다루지 않은 고액 자율 판정의 가능성을 실험으로 입증한다.

초안(Draft)2026 제출 대상: Applied Sciences / Future Internet (SCIE, 확인 예정) 314건 블라인드 · 942 판정

초록 (Abstract)

보험 업무는 계약 심사(언더라이팅)와 보험금 청구 심사의 2단계로 나뉘며, 양쪽 모두 고액·모호 건을 사람 심사자에게 상신한다. 본 연구는 두 단계에 대해 서로 다른 방식으로 AI 에이전트의 역할을 규명한다. Part A(계약 심사)에서는 세 에이전트(오케스트레이터·언더라이팅 서브에이전트·교차심사 리뷰어)로 이미 구현된 다중 에이전트 자율 심사 구조를 제시한다 — 등급(tier)은 LLM이, 처리 경로(route)는 코드가 결정하며 정상·경계 등급은 사람 개입 없이 자동승인된다. Part B(보험금 청구)에서는 선행연구가 사람·자문에 남겨 둔 고액 청구의 자율 판정 가능성을 실험으로 입증한다.

심어둔 정답과 이상(인젝션 포함)을 가진 314건의 블라인드 합성 사례(청약 90 + 청구 224)를 구성하고, 역량 높은 호스티드 모델(Codex)과 로컬 오픈웨이트 2종(Qwen-14B, DeepSeek-R1)이 블라인드 판정(승인/조사)하여 942건을 심어둔 정답과 대조했다. Part A 검증: 청약 심사 정확도는 역량 높은 모델 96.7%(자동구간 100%)로, 구현된 자율승인이 정확함을 뒷받침한다. Part B: 고액 청구 86.0%[79.8, 90.5]로 규칙이 0% 잡는 이상(코드–설명 불일치·업코딩)을 100% 포착하고 인젝션 11건을 모두 저항했다. 두 단계 모두 가치는 모델 의존적이어서 로컬 모델은 우연 수준(52–57%)이고, 금액 단독 과다(A3 55%)는 사람의 몫으로 남는다. 결론은 "계약 심사는 조건 충족 시 지금 자율 가능, 보험금 청구는 자율 가능성이 있으나 범주·모델 조건부"다.

키워드: 대규모 언어모델, AI 에이전트, 계약 심사, 언더라이팅, 보험금 청구, human-in-the-loop, 자율 심사, 이상 탐지, 프롬프트 인젝션, 모델 비교

1. 서론과 연구질문

보험은 두 번 심사한다 — 가입 시 계약 심사(언더라이팅), 지급 시 보험금 청구 심사. 두 단계 모두 소액·저위험은 규칙으로 자동 처리하고 고액·모호 건은 사람에게 상신하는데, 상신 흐름이 바로 규칙이 실패하는 지점(설명과 모순되는 치료코드, 한도 바로 아래로 쪼갠 청구, 형식상 일관되나 실질 의심되는 고지)이다. 여기에 LLM 에이전트를 넣자는 제안이 반복되나, 그 안전성은 모델 정확도와 선택한 모델에 달려 있으며 둘은 함께 측정되는 일이 드물다.

본 연구의 기여는 셋이다. (1) 계약 심사에 대해, 안전 게이트를 갖춘 구현된 다중 에이전트 자율 심사 구조를 제시하고 실험으로 그 판정 코어의 정확도를 검증한다(Part A). (2) 보험금 청구에 대해, 선행연구가 사람·자문에 남겨 둔 고액 자율 판정의 가능성을 규칙이 못 잡는 이상 유형에서 실험으로 입증한다(Part B). (3) 두 단계 모두에서 정확도가 모델 의존적임을 보이고, 오류 방향(누수 vs 과조사)·인젝션 강건성·판단 의존 범주로 자동화 경계를 조건화한다.

연구질문. RQ1(계약 심사): 구현된 자율 심사의 판정은 얼마나 정확한가? · RQ2(보험금 청구): 규칙이 못 잡는 고액 이상을 AI가 자율 판정할 수 있는가? · RQ3(모델 의존성·강건성): 정확도·오류 방향·인젝션 내성은 모델에 따라 어떻게 달라지는가? · RQ4(경계): 무엇을 자동으로 넘기고 무엇을 사람에게 남기는가?

2. 관련 연구 — 두 개의 공백

선행연구는 계약 심사·청구 양쪽에서 최종 판정을 사람·규칙에 남긴다. Islayem 외(Sci Rep 2025 [1])는 블록체인+LLM 사기탐지에서 GPT-4o 99%를 보고하나 최종은 사람이고 서술문이 불일치를 직접 기술한다. ClaimPilot(Future Internet 2026 [2])은 수의 청구를 8개 에이전트로 처리하되 판정은 결정론 코드가 하고 사람 게이트를 둔다. InsClaimBench(2026 [3])는 청구 판정을 결정 체인으로 나눠 사람과 비교하는 벤치마크다. Roy & Singh[4]는 언더라이팅 에이전트에 비판 에이전트를 붙이되 전건 사람 승인을 전제한다.

따라서 두 공백이 남는다 — (A) 계약 심사를 안전 게이트와 함께 실제로 자율화한 구현·검증, (B) 고액 청구를 AI가 자율 판정할 때의 정확도·오류 방향·모델 의존성. 본 연구는 둘을 각각 Part A·B로 다룬다.

PART A — 계약 심사: 구현된 AI 에이전트 자율 심사

3. 구현된 다중 에이전트 자율 심사 구조

계약 심사에서 "AI 에이전트 심사자"는 가설이 아니라 코드로 구현되어 있으며 세 에이전트로 구성된다.

  • ① 메인 오케스트레이터 — 요청을 처리하고 정밀 심사가 필요하면 run_underwriting_review로 위임.
  • ② 언더라이팅 서브에이전트 — 자체 도구호출 루프로 assess_* 심사도구 19종을 골라 실행 → submit_underwriting_decision으로 구조화 결론(tier 등) 제출.
  • ③ 교차심사 리뷰어 — 경계·중위험만 건강 관점(10종)·신용·행동 관점(9종) 리뷰어 둘이 독립 재검, 불일치 시 항상 더 보수적(상향), 완화 경로 없음.
[요청] → ① 오케스트레이터 ──(위임)──▶ ② 언더라이팅 서브에이전트(LLM) │ assess_* 19종 tool-calling ▼ submit_underwriting_decision → {tier} ├─ tier=경계/중위험 ─▶ ③ 교차심사 건강∥신용·행동 → 상향만 ▼ tier → route 는 "코드"가 결정 (모델 아님) ┌────────────────┬──────────────────┬───────────────────┐ 정상·경계 → 자동승인 중위험 → 보완(1회) 고위험·불명 → 수동심사 (경계는 사후 샘플감사) (재차 중위험→수동) 파싱 실패도 수동으로 안전 수렴

4. Part A 검증 — 청약 심사 실험 결과

구현된 자율승인이 정확한가를 314건 중 청약 90건으로 검증한다. 역량 높은 모델은 자동승인 구간(정상·경계가 모이는 자동 구간)에서 100%, 수동심사 구간에서 95%로 전체 96.7%다.

Part A 결론. 구현된 자율 심사의 판정 코어는 역량 높은 모델에서 청약 96.7%·자동 구간 100%·언더라이팅 이상 유형 100%로, 정상·경계 자동승인이 정확하다는 근거가 된다. 즉 계약 심사의 AI 에이전트 자율화는 (안전 게이트와 함께) 지금 활용 가능한 수준이다.
단, 모델 의존적. 같은 청약에서 로컬 모델은 58.9%로 우연 수준이다 — 자율 심사 배치는 역량 높은 모델 + 코드 게이트 조합에서만 안전하며, 약한 모델 대체는 위험하다. 또한 본 실험은 단일 판정으로, assess_* 도구를 실제 호출하는 전체 에이전트 루프 평가는 향후 과제다.
PART B — 보험금 청구: 선행 미개척 고액 자율 판정의 가능성

5. 고액 자율 판정 실험 설계

선행연구가 사람·자문에 남겨 둔 고액 청구의 자율 판정을, 314건 중 청구 224건(소액 60 + 고액 기본 90 + 고액 복잡 74)으로 "맡긴다면 얼마나 정확한가"로 측정한다. 각 사례는 심어둔 정답(승인/조사)과 이상 태그(A1 중복·A2 코드–설명 불일치·A3 금액과다·A4 분할·A5 면책, X1~X3 복잡·업코딩), 인젝션(일부)을 가진다. 세 모델이 블라인드 판정, 라벨 동결·검증 후 심어둔 정답 대비 채점(Wilson 95% CI·오류 방향·인젝션).

종합

7. 논의 — 조건부 결론

계약 심사는 조건 충족 시 지금 자율 가능. 안전 게이트(route=코드, 교차심사 상향, 실패→수동)를 갖춘 자율 심사가 이미 구현돼 있고, 역량 높은 모델에서 청약 96.7%·자동 구간 100%로 정확하다. 사람은 중위험 보완·고위험만 본다.

보험금 청구는 자율 가능성이 있으나 범주·모델 조건부. 고액 86%, 규칙 0% 범주 100%, 인젝션 완전 저항 — 선행이 사람에 남긴 영역을 상당 부분 자율화할 수 있음을 시사한다. 단 A3(금액 과다)는 사람 몫, 약한 모델은 위험하게 실패한다(누수 99/과조사 94).

공통 — 가치는 모델 의존적. 두 단계 모두 로컬 모델은 우연 수준이다. 따라서 "LLM을 쓴다"가 아니라 "어떤 모델이, 어떤 범주에서, 어떤 오류 방향으로"가 배치 조건이며, 이는 사이버보안 도메인의 "방어자 모델이 효과를 좌우한다"는 모델 의존성 결과와 같은 구조다.

8. 한계와 향후

  • 합성·AI 채점. 사람 gold 아님 → 사람 전문가 검증 30~40건·2차 라벨러 계획.
  • 재현성·반복. Codex는 어시스턴트 세션 실행(동급 API 재측정 필요), 단일 실행 → ≥3회 반복·2차 벤더.
  • 에이전트 루프 미평가. 단일 판정만 측정 → assess_* 호출 전체 루프 평가.
  • 보정·기준선. ECE/Brier·전통 ML 기준선·"근거 부족" 기권 추가.
  • 규칙 범위. 20% 규칙·이상 정의는 본 시스템 기준 — 외적 타당성 한계.

9. 결론

보험의 두 심사 단계에 대해 AI 에이전트의 역할을 구분해 규명했다. 계약 심사에서는 안전 게이트를 갖춘 다중 에이전트 자율 심사가 이미 구현돼 있고 역량 높은 모델에서 정확함을 보였다(청약 96.7%). 보험금 청구에서는 선행이 사람에 남긴 고액 자율 판정이, 규칙이 못 잡는 이상에서 가능함을 실험으로 입증했다(고액 86%·규칙 0% 범주 100%·인젝션 완전 저항). 두 단계 모두 가치는 모델 의존적이며, 금액 단독 판단은 사람에게 남는다. 요지는 "계약 심사는 지금 자율, 보험금 청구는 조건부 자율"이다.
